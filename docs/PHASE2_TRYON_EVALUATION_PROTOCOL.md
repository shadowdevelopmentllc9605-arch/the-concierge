# Photographic virtual try-on evaluation protocol
Status: NOT RUN. No renderer is approved or integrated by this protocol.
## Scope
Use the candidate decision in PHASE2_TRYON_RENDERER_DECISION.md. Start with a commercially cleared pipeline; do not use customer scans, retailer catalog photographs or model weights without documented rights. Do not enable a paid endpoint or new infrastructure without approval.
## Repeatable run
1. Pin renderer release, dependency/weight versions and configuration SHA-256. Record hardware and all model, weights, parser, dependency and input/output commercial rights reviews. Do not treat a permissive main repository license as clearance of its dependencies.
2. Prepare 14 original synthetic or licensed test-only image pairs: six tops (front, pattern, dark fabric, broad frame, seated, occluded), four bottoms (front, pattern, side, occluded), four one-pieces (front, pattern, side, occluded). Keep images and output outside the public repository; record fixture rights and SHA-256 digests. Include varied body proportions and appearances. Synthetic images are not real-world fit validation.
3. Run in an isolated environment. Record every attempt, including failures, wall-clock latency, peak memory and actual per-image cost including compute; record output SHA-256. Verify no customer data, external retention behavior and deletion of evaluation copies.
4. Review output beside source and garment. Score identity, garment detail (pattern, color, neckline, closures), silhouette and occlusion on a 1–5 rubric: 1 unusable, 2 major errors, 3 visible errors, 4 minor errors, 5 faithful. Mark critical artifacts (identity change, unintended exposure, missing limbs, severe garment substitution) independently; any such artifact blocks eligibility.
5. Provide evidence metadata to evaluateRenderer in scripts/tryon/evaluateRenderer.mjs. The exported CASES and DIMENSIONS define the fixed manifest; inspect the function and tests for field format. Invoke with node --input-type=module -e 'import {readFileSync} from "node:fs"; import {evaluateRenderer} from "./scripts/tryon/evaluateRenderer.mjs"; const r=evaluateRenderer(JSON.parse(readFileSync(process.argv[1],"utf8"))); console.log(JSON.stringify(r,null,2)); if(!r.eligible)process.exitCode=1' /path/to/report.json
6. Initial screening requires all 14 cases, each dimension >=4, no critical artifacts, no failures, documented commercial clearance, privacy checks, <=30 seconds and <=$0.10 per image. These are provisional engineering targets, not an approved budget or SLA. Preserve source evidence for independent review. The gate validates submitted metadata, not the truth of a license, hashes against actual files, reviewer identity or image quality. Passing it authorizes no production deployment.
7. After a real candidate passes screening, test repeatability, larger diverse samples, Android performance, explicit photo consent and deletion, access isolation, and retailer asset rights. Appearance is not a size/fit guarantee.
